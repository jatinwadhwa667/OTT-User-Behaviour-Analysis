# OTT User Behaviour Analysis

## Project Overview
This project analyzes OTT user behaviour and viewing patterns using Python. The goal is to understand user preferences, subscription engagement, and viewing habits.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Key Tasks
- Loaded and explored OTT user data.
- Cleaned missing and inconsistent values.
- Standardized data values and corrected data types.
- Analyzed popular content genres.
- Compared viewing hours across subscription types.
- Analyzed user age groups and device preferences.
- Identified low-engagement users using the 25th percentile.

## Key Insights
- Most popular genre: Comedy
- Subscription with highest watch time: Premium
- Largest age group: Adult (26-45)
- Most popular devices among Premium users: Tablet, Tv
- Low-engagement users watch 7.00 hours or less per week.

- `ott_user_behavior_analysis.py` – Python analysis code.
